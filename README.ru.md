# Multimodal RAG Knowledge Base

**База знаний для самостоятельного размещения: загрузка, проверка, публикация и ответы со ссылками на источники.**

Текст, PDF, изображения, аудио и видео в общей библиотеке. Изоляция компаний и ролей, сохранение оригиналов, локальные модели или удалённые API.

## Возможности

- **Поиск по разным модальностям:** текстовые embeddings с описаниями/расшифровками или мультимодальные embeddings, если их поддерживает провайдер.
- **Проверка перед публикацией:** исправление OCR, описаний и расшифровок. Действующая версия остаётся доступной до готовности замены.
- **Проверка источников:** цитаты, оригиналы, медиафрагменты и поиск точной фразы в длинном документе.
- **Разделение доступа:** компании, роли пользователя/редактора/администратора, права на базы и независимый владелец платформы. Личные беседы остаются личными.
- **Выбор AI:** Ollama, Whisper, Google, Anthropic и совместимые с OpenAI API; назначения задач, подключения и зашифрованные ключи разделены.
- **Рабочие процессы:** очереди заданий, синхронизация папок, оценка расходов, проверки качества, аудит и проверяемые резервные копии.

## Локальный запуск

Нужны **Node.js 24.19+** и **Docker с Compose v2**. Yarn закреплён в репозитории. Если команды `yarn` нет, заменяйте её на `node .yarn/releases/yarn-4.18.1.cjs`.

```sh
git clone https://github.com/ichernetskii/multimodal-rag-knowledge-base.git
cd multimodal-rag-knowledge-base
yarn install --immutable
yarn configure
yarn infra:up
yarn cli init
yarn seed
yarn dev
```

Откройте **http://localhost:5173**. Учебная учётная запись: **`admin` / `local-development-only`**. По умолчанию используется явно обозначенный **TEST AI** без ключей провайдера: он демонстрирует сценарии, но не даёт настоящих ответов LLM. `yarn configure` создаёт приватные локальные параметры в игнорируемом `.env`.

При следующих запусках достаточно `yarn infra:up` и `yarn dev`. Дождитесь API и обработчиков; готовность проверяется через `http://127.0.0.1:3210/health/ready`.

Для PDF/OCR/аудио/видео вне контейнеров выполните один раз `yarn prepare:pdf` и `yarn prepare:media`. Готовая среда обработки включена в [Docker с локальными моделями](docs/DEVELOPMENT.md#local-models-in-docker). При сбоях смотрите [диагностику запуска](docs/DEVELOPMENT.md#startup-troubleshooting).

## Первая база знаний

1. Войдите, выберите компанию и создайте базу в **Knowledge base → Knowledge bases & access**. Назначьте доступ команде.
2. Загрузите материалы, сверьте обработанный текст с оригиналом, исправьте ошибки, опубликуйте и дождитесь индексации.
3. Задайте вопрос в **Conversations** и откройте цитаты.

Чтобы импортировать все девять [учебных материалов](examples/knowledge-base/README.ru.md), оставьте API и обработчики запущенными:

```sh
yarn cli login admin
yarn cli tenants list
yarn cli tenant-use COMPANY_UUID
yarn demo:import
```

Импорт создаёт отдельную базу для проверки. Реальные провайдеры могут брать плату за обработку и индексацию. Для настоящих ответов владелец платформы подключает модели и ключи, а администратор компании назначает модели задачам. [Руководство по моделям и медиа](docs/MEDIA.md) объясняет описания, распознавание речи и смену моделей.

## Разработка и развёртывание

React/Vite/TypeScript → Node.js API и обработчики → PostgreSQL (pgvector, RLS, pg-boss), приватное S3 и восстанавливаемый кеш Redis. CLI использует тот же публичный API.

```sh
yarn validate            # контракты, документация, типы, линтеры, тесты, сборка
yarn test:integration    # отдельные БД/S3; нужна инфраструктура разработки
yarn test:docker         # одноразовое развёртывание и настоящая обработка медиа
```

[Разработка](docs/DEVELOPMENT.md) · [Конфигурация](docs/CONFIGURATION.md) · [Production и восстановление](docs/OPERATIONS.md) · [Вклад в проект](CONTRIBUTING.md) · [Проверки](docs/VERIFICATION.md)

**Статус:** проект до первого релиза; один актуальный формат БД/API без автоматических миграций старых данных разработки. Production требует приватной конфигурации, HTTPS, оператора и реальных провайдеров; учебные seed и TEST AI запрещены. Расходы оценочные. SSO/SAML, платежи, диктовка вопросов и корпоративные DLP/антивирус пока вне [границ продукта](docs/REQUIREMENTS.md).
