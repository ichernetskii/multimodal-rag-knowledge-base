# Требования 11–21: реализация и проверка

Матрица связывает требования с текущей реализацией и датированными проверками. Число тестов и время последнего автоматического прогона — в [checks.json](verification/checks.json); состав и ограничения проверок — в [VERIFICATION.md](VERIFICATION.md). Результаты браузера, live-моделей и native production относятся к датам соответствующих протоколов, а не ко всем последующим изменениям. Изменения промышленной специализации и отказ от обратной совместимости заменяют соответствующие первоначальные требования. Правила: [AGENTS.md](../AGENTS.md). П — автоматические product-тесты в server/tests/product.test.ts; М — сквозной server/scripts/test-product-live.ts с настоящими EmbeddingGemma/Qwen и локальным OCR; Б — проверка браузером на desktop и мобильном viewport, включая загрузку, ответ, перезагрузку и все разделы админки. Базовые тесты RAG дополнительно входят в validate. Детальные измерения М — [verification/live.json](verification/live.json), результаты датированной проверки UI — [verification/ui.json](verification/ui.json).

В колонке CLI операции перечислены как API actions: каждая запускается командой `yarn cli api <action> input.json` и выполняет тот же код, что UI. Отдельные удобные команды указаны явно. Результат «прошло» означает успешную проверку описанного сценария, а не обещание отсутствия любых ошибок на произвольных документах.

Ограничения измерений: OCR проверен на четырёх небольших контролируемых PDF; сложная верстка требует просмотра извлечения. Контроль facts проверяет ожидаемые строки и не заменяет инженерную проверку произвольного ответа. OCR memory limit через RLIMIT_AS относится к Linux; на macOS общий потолок памяти задаётся средствами ОС. Тест reverse proxy использует потоковый HTTP-прокси; nginx-конфигурация предоставлена, конкретная установка nginx/TLS на этом компьютере не выполнялась. Шаблоны systemd/launchd предоставлены и не устанавливались как системные службы.

Отдельная production-проверка: [native-production.json](verification/native-production.json). Измерения и границы результата: [VERIFICATION.md](VERIFICATION.md). Контейнеры, nginx/TLS и системные службы требуют приёмки на целевой машине; наличие конфигурации не означает выполненное развёртывание. Контрольный набор предназначен для общих баз; административный отчёт скрывает недоступные личные источники.
