# Использование

После [установки](../README.ru.md) откройте клиент: localhost:5173 в разработке или localhost:8080 с нативным production gateway. API на порту 3210 предназначен для запросов, а не для открытия интерфейса. Для удалённой установки адрес задаёт администратор.

## Роли и вход

| Роль          | Что доступно                                                                                      |
| ------------- | ------------------------------------------------------------------------------------------------- |
| Пользователь  | Свои диалоги и вложения, поиск и чтение разрешённых баз                                           |
| Редактор      | То же и управление документами баз, где назначен edit; переименование таких баз                   |
| Администратор | Пользователи/группы, создание баз и ACL, настройки, качество, синхронизация, копии и эксплуатация |

Роль редактора сама по себе не даёт доступ ко всем базам: нужны назначения пользователю или его группе. Администратор видит общие базы, но не получает чужую личную переписку и вложения автоматически. В меню аккаунта можно сменить свой пароль, посмотреть/отозвать сессии и выйти. Смена пароля отзывает сессии; войдите снова. Для восстановления администратора без email есть [локальная CLI](CLI.md#скачивание-копии-и-recovery).

## Первая база и документы

1. Создайте администратора в локальном мастере, выберите каталог/лимиты и проверьте доступность моделей. Мастер можно завершить переходом в библиотеку и вернуться к загрузке обычным способом.
2. Создайте первую базу. Позже в «Администрирование → Базы и доступ» администратор назначает пользователям и группам read/edit.
3. В «Документы» выберите базу и загрузите PDF, TXT, `.md` или `.markdown`. Текстовые файлы должны быть UTF-8. Текущие лимиты показаны в форме.
4. До отправки просмотрите результат проверки: новый документ, совпадение содержимого, предполагаемое обновление, неподдерживаемый формат или лимит. Совпадение имени — кандидат на новую версию; содержимое проверяется отдельно. Файлы отправляются последовательно, обработка идёт в фоне.
5. Дождитесь завершения. Для OCR откройте извлечённые страницы, проверьте текст и предупреждения и нажмите «Текст проверен · опубликовать». Пустые страницы и ошибки OCR блокируют публикацию даже после подтверждения.

Список документов поддерживает поиск по названию, базу/состояние, сортировку, страницы и пакетные действия. Поиск по тексту выполняется отдельно, без генерации: введите фразу или точное обозначение и откройте найденный раздел. Это отличается от фильтра по названию.

## Поиск и диалог

Создайте диалог и выберите базу до отправки. Пустой выбор означает все разрешённые общие базы. Вложения прикрепляются к текущему диалогу и дополняют выбранную базу; они не публикуются в общей библиотеке и не доступны другим пользователям.

Введите вопрос и нажмите «Отправить» или Ctrl/⌘+Enter. Сервер показывает очередь, поиск и генерацию. Отсутствие достаточной информации, уточнение вопроса, отмена, прерывание и техническая ошибка — разные состояния. Укажите более точный вопрос или область поиска, если найденные источники не подходят. Векторная близость не является вероятностью правильности ответа.

Нажмите номер цитаты или источник под ответом: откроется сохранённая версия, конкретная страница/раздел и использованный фрагмент с контекстом. Оригинал можно открыть и скачать при действующих правах. После обновления документа старый ответ сохраняет ссылку на прежнюю версию, а новый поиск использует опубликованную активную версию.

Если чтение старых сообщений остановило автопрокрутку, кнопка «К последнему сообщению» вернёт вниз. «Копировать» требует HTTPS или localhost; при недоступном Clipboard API можно выделить текст вручную. Markdown, таблицы и код отображаются без исполнения HTML/сценариев; внешние изображения из текста модели не загружаются.

## Черновики и версии разговора

Диалоги доступны в списке с поиском, переименованием и удалением. Черновик сохраняется на сервере с небольшой задержкой; после завершения сохранения его увидит другое устройство. Перезагрузка восстанавливает выбранную ветку и незавершённые задания. Закрытие вкладки само по себе не отменяет работу сервера.

«Редактировать вопрос» создаёт новый вариант, «Повторить» — ещё один ответ на тот же вопрос. Старые результаты сохраняются. Через «Версии вопроса» выберите нужный вариант: последующие сообщения продолжат его цепочку. Удаление диалога удаляет его личные вложения и историю; экспортируйте нужное заранее. Экспорт JSON содержит все сохранённые ветки и разрешённые источники.

При отзыве доступа сервер скрывает производные ответы и источники, даже если они были сохранены ранее. Клиент обновляет разрешения и закрывает устаревшие окна. Скачанные до отзыва файлы находятся вне управления сервера.

## Версии и удаление документов

«Новая версия» обновляет существующий документ, сохраняя UUID. Пока новая версия проходит извлечение/проверку, предыдущая опубликованная версия остаётся доступной. Во вкладке версий можно сравнить извлечённый текст по страницам, открыть оригинал и выбрать ранее проиндексированную версию кнопкой «Использовать эту версию». Переименование не создаёт дубликат.

| Действие             | Результат                                                                                                      |
| -------------------- | -------------------------------------------------------------------------------------------------------------- |
| Исключить из поиска  | Документ перестаёт участвовать в новом поиске; оригинал и история сохраняются                                  |
| Архивировать         | Архивное состояние, также без участия в новом поиске; можно вернуть в работу                                   |
| Удалить окончательно | Удаляются оригиналы, версии, индекс, кеши и производные данные; использованные ответы теряют содержимое/ссылки |

Права проверяются сервером для каждого действия. При конфликте ревизий перечитайте запись и повторите своё изменение: сохранение поверх чужой правки не выполняется автоматически.

## Администрирование

- **Пользователи / Базы и доступ:** роли, блокировка, группы, смена пароля и отзыв сессий, назначения read/edit. Пустой новый пароль в форме пользователя сохраняет прежний. Последнего активного администратора нельзя отключить.
- **Качество:** жалобы и неотвеченные вопросы, версии источников, настройки, контрольный набор и результаты. «Оценить / ошибка» позволяет указать неверный источник, устаревание, отсутствие ответа, нерелевантный ответ или другую причину. Оценка не изменяет документы.
- **Синхронизация:** выберите папку на машине сервера, базу и политику удаления: keep, exclude или delete. Сначала посмотрите изменения, затем запустите вручную или задайте интервал; 0 означает только ручной запуск. Папка браузерного устройства автоматически серверу не доступна.
- **Резервные копии:** создание, проверка состава/целостности, список и восстановление. Настройте расписание и другой диск; восстановление завершает текущие сессии. Порядок действий — в [эксплуатации](OPERATIONS.md#резервное-копирование-и-восстановление).
- **Настройки / Эксплуатация:** модель ответа, промпт, лимиты/OCR/хранение, паузы и измеренные ресурсы/очереди. Изменения модели/промпта/поиска проверяйте контрольным набором. Недоступность генерации не отключает чтение документов и истории.

Контроль качества сопоставляет ожидаемые документы, ключевые строки, ссылки, отказ без источников и измеренное время. Набор предназначен для общих баз, не личных вложений. Техническую ошибку передавайте администратору с code и diagnostic; не требуется отправлять полные документы в технический журнал. Типовые причины и действия — в [runbook](OPERATIONS.md#диагностика-неисправностей).
