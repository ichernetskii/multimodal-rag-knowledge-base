# Учебная база знаний

Девять фиксированных материалов для проверки интерфейса, обработки, поиска и цитат. Правила и сервисные данные вымышлены. Файлы находятся отдельно от кода, рабочих данных и результатов тестов.

## Импорт

1. Запустите API и обработчики. Выполните `yarn cli login admin` и `yarn cli tenant-use COMPANY_UUID`.
2. Запустите `yarn demo:import`. Команда проверит SHA-256, создаст новую базу и загрузит материалы через API. Администратор компании назначает доступ; пользовательские разрешения изначально отсутствуют.
3. Сверьте OCR, описания и расшифровки с оригиналами, затем опубликуйте и дождитесь индексации.
4. Задайте вопросы из [manifest.json](manifest.json), откройте источники и сравните ожидаемые факты. Проверьте также отзыв доступа и личные вложения.

`yarn demo:import --publish` явно подтверждает публикацию учебных материалов без ручной проверки. Реальные модели могут расходовать бюджет. Каждый запуск создаёт отдельную базу; существующие документы не заменяются. Частичный сбой возвращает код 1 с базой, файлом, заданием и диагностикой. Принятые данные остаются для проверки. `seed` создаёт учебные учётные записи и компании, а не публикует корпус.

Видео статично и не проверяет понимание движения. Манифест содержит модальность, размер, хеш, вопрос и ожидаемые факты. Это ориентир для оценки человеком, а не требование дословного ответа.

TEST AI проверяет инфраструктуру, но не доказывает понимание изображений или качество ответов. Текстовым embeddings нужны описания от модели с изображениями и расшифровки Whisper/Google Gemini. Подготовленный текст проверяется до публикации. Мультимодальные профили должны отражать реальные возможности провайдера. PDF/OCR требует подготовленного runtime; ошибки модели и бюджета остаются видимыми.

`yarn test` проверяет целостность корпуса; `yarn test:docker` использует настоящие PDF/OCR, Whisper и видеодекодирование. При изменении файла обновите размер, SHA-256, ожидаемые факты и тесты. Результаты прогонов находятся в игнорируемом `.artifacts/verification/`.

Тексты, PDF и табличка созданы для проекта. Речь — из тестов whisper.cpp 1.9.1; [MIT-лицензия](media/WHISPER-LICENSE.txt) сохранена. Видео составлено из включённых изображения и речи. Команда воспроизведения сборки видео приведена в [английском README](README.md#provenance); для импорта используется готовый файл.
